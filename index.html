How to Play

🏏 BATTING:
• PULL (← / A): Leg side hook / pull / sweep.
• LOFT (↑ / W): High straight drive for 6!
• CUT (→ / D): Off side square cut / cover drive for 4.
• BLOCK (↓ / S): Drop ball for a quick single.
• RUN (SPACEBAR or RUN BUTTON): Sprint between wickets! Press again for a 2nd run, but beware of run outs!

⚾ BOWLING:
